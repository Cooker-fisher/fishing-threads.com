# DAIWA 電動リール spec selector 方針

## 主対象
- `製品スペック`
- 見出し行
- 値行
- 価格
- JAN
- 末尾注記

## ページ観察の要点
- `製品スペック` は本文ページ下部に同一URLで表示される
- 見出しは1行で並び、その直後にバリエーションごとの値行が続く
- 例: `アイテム / 標準自重 / 巻き取り長さ / ギア比 / 標準巻糸量PE / 最大ドラグ力 / JAFS基準巻上力 / メーカー希望本体価格 / JAN`
- 値行は `レオブリッツ 400J ... 4550133434808` のように横並びで続く
- 下に税抜き表記や巻糸量注記が続く

## 方針
- Shimano のような別URL spec ではなく、同一URL内 spec を切り出す
- 行全体を raw のまま保持しつつ、見出し群と値群を対応づける
- `メーカー希望本体価格` は `price_raw` としても引き上げる
- `JAN` は `jan_upc_raw` として引き上げる
- 末尾注記は `notes_raw` に分ける
