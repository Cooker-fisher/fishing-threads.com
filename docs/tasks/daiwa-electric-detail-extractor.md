# DAIWA 電動リール詳細ページ extractor 実装タスク分解

## 役割
- パンくずを取る
- 商品名 / 価格を取る
- 冒頭コピー / 冒頭本文 / 注記 / 画像を取る
- `1商品 = 1 JSON` の product raw を保存する

## やらないこと
- spec表の行対応づけ
- related / technology 全文の大量回収
- normalized 生成

## DAIWA 固有注意
- 商品名は日本語名 + 英字名で出ることがある
- `ダイワテクノロジー` と `製品詳細` は extra 扱い寄り
- `製品スペック` は同一URLだが別責務にする

## 最小タスク
1. HTML取得
2. パンくず抽出
3. 商品名 / 価格抽出
4. 冒頭説明抽出
5. 注記抽出
6. 画像抽出
7. JSON組み立て
8. slug生成
9. 保存
10. CLI
11. テスト
