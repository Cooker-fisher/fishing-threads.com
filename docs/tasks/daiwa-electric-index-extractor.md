# DAIWA 電動リール一覧 extractor 実装タスク分解

## 役割
- 一覧ページHTMLを取得する
- 検索結果一覧から `電動リール` を含む product link だけを抽出する
- `1ページ = 1 JSON` の raw を保存する

## やらないこと
- 詳細ページ取得
- spec 抽出
- normalized 生成

## DAIWA 固有注意
- 同一一覧にスピニングや両軸も混在する
- `電動リール` を含む行だけを採る
- `メーカー希望本体価格` 以降を `price_raw` に使う

## 最小タスク
1. HTML取得
2. ページ番号抽出
3. 商品ノード抽出
4. item抽出
5. JSON組み立て
6. 保存
7. CLI
8. テスト
