# 全体アーキテクチャ

## サイト定義
Tsuri-threads.com は、釣り具・規格・釣り物・ライン・仕掛けの関係をたどれる接続型データベースである。

## 主役
主役は entity 単体ページではなく、relation / setup である。

例:
- リール → 釣り物
- リール → ライン
- 釣り物 → 錘負荷
- 条件 → 候補セット

## データ層
- raw: 取得した事実の正本
- normalized: 比較しやすく整形した層
- derived: 一覧・比較・導線のための派生層

## UIの核
導線は以下を基本とする。
1. 魚種 / 条件を選ぶ
2. 必要番手帯を絞る
3. メーカー比較を行う
4. 上位下位比較を行う
5. setup へつなぐ

## 初期スコープ
まずは電動リール軸から始める。
将来はスピニング、ベイト、両軸、レバーブレーキなどへ拡張する。
